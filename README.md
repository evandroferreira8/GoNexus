# GO Nexus

Guias e ferramentas para sua jornada no Pokémon GO.

## Páginas
- `index.html` — Guia de Busca
- `calculadora.html` — Vale a Caixa?
- `efeitos-aventura.html` — Efeitos Aventura
- `poeira-estelar.html` — Poeira Estelar
- `evolucoes-especiais.html` — Evoluções Especiais: pré-requisitos de evolução
- `nav.js` — navegação compartilhada

## Estrutura compartilhada
O cabeçalho e o rodapé são componentes compartilhados definidos em `nav.js` e isolados com Shadow DOM, garantindo a mesma aparência e o mesmo comportamento responsivo em todas as páginas.
