# GO Nexus

Guias e ferramentas para sua jornada no Pokémon GO.

## Páginas

- `index.html` — Guia de Busca
- `calculadora.html` — Vale a Caixa?
- `efeitos-aventura.html` — Efeitos Aventura
- `poeira-estelar.html` — Poeira Estelar
- `nav.js` — menu compartilhado entre as páginas
- `nexus.css` — identidade visual compartilhada do cabeçalho e rodapé

## Manutenção do menu

Para adicionar uma nova ferramenta ao menu, crie o novo arquivo HTML e acrescente uma entrada ao array `pages` em `nav.js`. As páginas que carregam `nav.js` passarão a exibir a nova opção automaticamente.
